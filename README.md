# Power Booster GP

เกมแข่งเซิร์ฟบอร์ดติดไอพ่นตัวละครชิบิ 3D บนเว็บ — Booster 3 จังหวะ, ไอเทมโจมตี, แท่นกระโดด, เล่นออนไลน์ได้ 8 คน, เล่นบนมือถือและติดตั้งเป็นแอป (PWA) ได้

## รันบนเครื่องตัวเอง

```bash
npm install
npm start
```

เปิด http://localhost:3000 — เพื่อนที่อยู่ Wi-Fi เดียวกันเปิดที่อยู่ `Same Wi-Fi/LAN` ที่เซิร์ฟเวอร์พิมพ์ออกมา

## Deploy ขึ้น Render (ได้ HTTPS → ติดตั้งเป็นแอปบนมือถือได้ + เล่นออนไลน์ข้ามเน็ต)

1. สร้าง repository ว่างบน GitHub (แนะนำ Private) แล้ว push โค้ดนี้ขึ้นไป:
   ```bash
   git remote add origin https://github.com/<ชื่อบัญชี>/power-booster-gp.git
   git push -u origin main
   ```
2. เข้า https://dashboard.render.com → **New** → **Blueprint** → เชื่อมบัญชี GitHub → เลือก repository นี้ → **Apply**
   Render จะอ่าน `render.yaml` แล้วสร้าง web service ให้อัตโนมัติ
3. รอ build เสร็จ (ประมาณ 1–3 นาที) จะได้ลิงก์แบบ `https://power-booster-gp.onrender.com`
4. เปิดลิงก์นั้นบนมือถือ → ปุ่ม **📲 ติดตั้งเป็นแอป** (Android) หรือ แชร์ → **เพิ่มไปยังหน้าจอโฮม** (iPhone)

หลังจากนี้ทุกครั้งที่ `git push` Render จะ deploy เวอร์ชันใหม่ให้อัตโนมัติ

**หมายเหตุแพ็กเกจฟรีของ Render:** ถ้าไม่มีคนเข้าเกิน 15 นาที เซิร์ฟเวอร์จะหลับ การเปิดครั้งถัดไปจะช้าประมาณ 30–60 วินาที
(ห้องออนไลน์ที่ค้างอยู่จะหายไปด้วย) ถ้าต้องการให้ตื่นตลอดให้อัปเกรดเป็นแพ็กเกจเสียเงิน

## ไฟล์หลัก

| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | เซิร์ฟเวอร์ Node: ส่งไฟล์เกม + ห้องเล่นออนไลน์ (WebSocket) |
| `js/game.js` | ลูปเกม, นักแข่ง, AI, ไอเทม, Booster, HUD, ซิงก์ออนไลน์ |
| `js/track.js` | ด่าน, ฉาก, แท่นกระโดด, สิ่งก่อสร้าง |
| `js/chibi.js` | ตัวละครชิบิและท่าทาง |
| `js/fx.js` | เอฟเฟกต์ภาพ (bloom, blur, ท้องฟ้า, น้ำ, ลาวา, อนุภาค) |
| `js/optimize.js` | รวมชิ้นส่วน 3D และระดับคุณภาพกราฟิก |
| `js/touch.js` | ปุ่มควบคุมบนมือถือ |
| `sw.js`, `manifest.webmanifest`, `js/pwa.js` | PWA (ติดตั้งเป็นแอป / เล่นออฟไลน์) |
