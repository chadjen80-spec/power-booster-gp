# ใช้โมเดลตัวละครจาก Blender

เกมรองรับโมเดลตัวละครจาก Blender (ไฟล์ `.glb`) แทนตัวละครชิบิที่สร้างจากโค้ด
บอร์ดเซิร์ฟ ไฟไอพ่น และโล่ ยังเป็นของเกมเหมือนเดิม — โมเดลจาก Blender คือ **ตัวคนที่ยืนบนบอร์ด**

## เริ่มเร็วที่สุด: แก้จากไฟล์ตั้งต้น

ในโฟลเดอร์ `models/templates/` มีตัวละครทั้ง 8 ตัวที่ export จากเกมไว้ให้แล้ว (ชื่อชิ้นส่วนและจุดหมุนถูกต้องครบ)

1. เปิด Blender → **File → Import → glTF 2.0 (.glb/.gltf)** → เลือก เช่น `models/templates/sky.glb`
2. แก้ได้ตามใจ: ปั้นรูปทรงใหม่, เปลี่ยนสี, เพิ่มเสื้อผ้า/เครื่องประดับ, ใส่ texture
   **อย่าเปลี่ยนชื่อ** object ในกรอบด้านล่าง และอย่าย้ายลำดับแม่-ลูก (parent) ของมัน
3. **File → Export → glTF 2.0** ตามการตั้งค่าในหัวข้อ "การ export" แล้วบันทึกเป็น `models/sky.glb`
   (ชื่อไฟล์ = id ของตัวละคร: `nova` `blaze` `frost` `leaf` `ruby` `dusk` `sky` `sunny`)
4. รัน `npm start` แล้วรีเฟรชหน้าเกม — ตัวละครนั้นจะเปลี่ยนเป็นโมเดลใหม่ทันที
   อยากกลับไปใช้ตัวเดิม แค่ลบไฟล์ `models/sky.glb`

## ชื่อชิ้นส่วน (สำคัญ)

เกมขยับตัวละครเองตอนเลี้ยว ดริฟต์ กระโดด และโดนโจมตี โดยหา object จาก **ชื่อ**:

| ชื่อ object | คือส่วนไหน | จุดหมุน (Origin) ต้องอยู่ที่ | เกมทำอะไรกับมัน |
|---|---|---|---|
| `Legs` | ขา + รองเท้า | ระดับพื้น ใต้เท้า | ย่อ (บีบความสูง) ตอนย่อตัว |
| `Upper` | ลำตัวท่อนบนทั้งหมด (ลูกของมันคือแขน หัว ปีก) | สะโพก | เอียง/บิดเข้าโค้ง และโน้มตัวไปข้างหน้า |
| `Head` | หัว (อยู่ใต้ `Upper`) | กลางหัว | หันมองทางโค้ง |
| `ArmL` / `ArmR` | แขนซ้าย / ขวาของตัวละคร (อยู่ใต้ `Upper`) | หัวไหล่ | กางแขน ยกแขนตอนกระโดด |
| `Hair...` (ขึ้นต้นด้วย Hair) | ช่อผม/หางม้า/ผ้าคลุม ที่ควรพลิ้ว | โคนผม | สะบัดตามแรงเหวี่ยงและลม |

- ไม่มีชิ้นไหนก็ได้ — เกมจะข้ามการขยับส่วนนั้น (โมเดลก้อนเดียวไม่มีชื่อเลยก็โหลดได้ แค่จะไม่ขยับท่า)
- แขนในเกมถูกตั้งมุมใหม่ทุกเฟรม: ถ้าปั้นแขนใหม่ ให้ปั้นแขน **ห้อยลงตรงๆ** จากหัวไหล่ แล้ววางไว้ใน `ArmL`/`ArmR`
- ซ้าย/ขวา นับจากตัวละครเอง (`ArmL` อยู่ทางแกน X บวก)

## ทิศ ขนาด และตำแหน่ง

- **หน้าตัวละครหันไปทาง -Y ของ Blender** (คือมองจากมุม Front ด้วยปุ่ม Numpad 1 แล้วเห็นหน้า)
- ขนาดเท่าไหร่ก็ได้ เกมจะย่อ/ขยายให้สูง 2.9 หน่วยเท่าตัวละครเดิมโดยอัตโนมัติ (วัดจากจุดต่ำสุดถึงสูงสุด)
- จุดต่ำสุดของโมเดล = เท้า ที่จะวางบนบอร์ด (ระวังของที่ห้อยต่ำกว่าเท้า)
- สไตล์ชิบิ: หัวใหญ่ประมาณครึ่งหนึ่งของความสูงทั้งตัว

## วัสดุ (Material) และ texture

- ใช้ **Principled BSDF** ปกติ: ใส่สีที่ Base Color หรือต่อ Image Texture เข้า Base Color
- เกมจะแปลงเป็นแสงเงาแบบการ์ตูน (toon) ให้เองเพื่อให้เข้ากับตัวละครอื่น
- ใบหน้าในไฟล์ตั้งต้นเป็นวัสดุแบบ "unlit" (ไม่รับแสง) จะสว่างคงที่ ถ้าไม่ได้แก้ก็คงไว้แบบนั้น
- texture ไม่ควรเกิน 1024×1024 พิกเซล

## การ export

**File → Export → glTF 2.0 (.glb/.gltf)** แล้วตั้งค่า:

| ตัวเลือก | ค่า |
|---|---|
| Format | **glTF Binary (.glb)** |
| Include → Limit to | เลือกเฉพาะตัวละคร (ไม่ต้องมี กล้อง/ไฟ/พื้น) |
| Transform → +Y Up | **เปิด** (ค่าเริ่มต้น) |
| Mesh → Apply Modifiers | **เปิด** |
| Material | Export |
| Compression (Draco) | **ปิด** — เกมยังไม่รองรับ |
| Animation | ปิดได้ — เกมขยับท่าเอง ยังไม่ใช้ animation จาก Blender |

## ขนาดไฟล์ (สำหรับมือถือ)

- ไม่เกินประมาณ **15,000 สามเหลี่ยม** ต่อตัว (ดูที่ Statistics ใน Viewport Overlays)
- ไฟล์ไม่เกินประมาณ **2 MB** ต่อตัว — เกมโหลดทุกตัวตอนเปิด

## ยังไม่รองรับ

- โครงกระดูก (Armature/bones) และ animation ที่ทำใน Blender — ตอนนี้เกมขยับท่าด้วยการหมุน object ตามชื่อข้างบน
  ถ้าโมเดลมี armature ให้แยกเป็น object ตามชื่อแทน (หรือขอให้เพิ่มการรองรับ bones ได้)
- Draco compression

## เพิ่มตัวละครใหม่ทั้งตัว

1. เพิ่มรายการใหม่ใน `PB.CHARACTERS` ใน `js/chibi.js` (คัดลอกตัวเดิม 1 บรรทัด เปลี่ยน `id` และ `name`)
2. เพิ่ม `id` เดียวกันใน `CHAR_IDS` ใน `server.js` (สำหรับเล่นออนไลน์)
3. วางโมเดลเป็น `models/<id>.glb`

## ขึ้นเว็บและแอป

ไฟล์ใน `models/*.glb` จะถูกส่งขึ้นทั้งเว็บ (Render) และแอป Android อัตโนมัติเมื่อ `git push`
(โฟลเดอร์ `models/templates/` เป็นไฟล์ตั้งต้นสำหรับแก้ใน Blender เท่านั้น ไม่ถูกใส่ลงในแอป)
